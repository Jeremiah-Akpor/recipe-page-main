## Built with

- Semantic HTML5, ordered and unordered lists, and an accessible nutrition table
- CSS Flexbox, nesting, and media queries
- Local Young Serif and Outfit fonts

## What I learned

I used ordered lists for recipe steps, an unordered list for ingredients, and a table for nutritional information. CSS `::marker` helped style list markers, while cell borders and `border-collapse` helped style the nutrition table.

On mobile, I removed the recipe card padding to let the image reach the screen edges, then added horizontal padding to the non-image direct children. This helped me understand how parent padding affects its children.
